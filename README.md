# Control of Self-Driving Vehicles

Course website and Python exercises for a four-day, hands-on Smart Vehicles Summer School module.

## Documentation

The site is built with MkDocs Material.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-docs.txt
mkdocs serve
```

On Windows PowerShell, activate the environment with:

```powershell
.\.venv\Scripts\Activate.ps1
```

The public site will be available at:

https://rudolfkrecht.github.io/smart_vehicles_control/
